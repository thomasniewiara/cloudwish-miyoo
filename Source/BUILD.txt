Build the native binary on Linux x86_64:
1. Install the Miyoo toolchain from shauninman/union-miyoomini-toolchain.
   This build used the archive:
   https://github.com/shauninman/miyoomini-toolchain-buildroot/releases/download/v0.0.3/miyoomini-toolchain.tar.xz
   Extract with tar --no-same-owner -xf miyoomini-toolchain.tar.xz -C /opt
2. Run sh Source/build.sh from the package root.
   Override MIYOO_TOOLCHAIN if installed somewhere other than
   /opt/miyoomini-toolchain. SDL headers/libraries come with that toolchain.
3. The output replaces Roms/PORTS/Games/Cloudwish/cloudwish.

Assets are already prepared; Python is not needed to build or play.
To regenerate assets from the original Cloudwish PNG folder, install Pillow
and DejaVu Sans, then run python3 Source/prepare_assets.py /path/to/png/folder
The four creature images originated in the user's Cloudwish game project.
The meadow background and Pip are drawn procedurally for this demo.
The bitmap font is derived from DejaVu Sans; license in FONT-LICENSE.txt.

Desktop testing requires SDL 1.2 headers and libraries:
cc -std=gnu99 -O2 -Wall -Wextra Source/cloudwish.c $(sdl-config --cflags --libs) -lm -o /tmp/cloudwish-host
/tmp/cloudwish-host --self-test
cc -std=gnu99 -O2 -Wall -Wextra Source/test_progression.c $(sdl-config --cflags --libs) -lm -o /tmp/cloudwish-test
/tmp/cloudwish-test
For a desktop run, change into Roms/PORTS/Games/Cloudwish before launching.
Desktop keys mirror Onion SDL events:
Arrows = D-pad; Space = A; Left Ctrl = B; Left Alt = Y;
E/T = L1/R1; Tab/Backspace = L2/R2; Enter = START.
Snapshot: SDL_VIDEODRIVER=dummy /tmp/cloudwish-host --screenshot /tmp/frame.bmp
Optional snapshot arguments: mission index 0–7, then any word for puzzle view.

The game draws on its own software canvas and SDL blits it to the hardware
surface. It does not write directly into framebuffer memory or assume its
row stride. No private SDL library is shipped.

Host display regression test (run from game's assets parent directory):
Compile Source/test_display.c with the same host SDL flags as test_progression.
Run SDL_VIDEODRIVER=dummy /path/to/test_display
The test compares all RGB pixels of canvas and display across four views.
